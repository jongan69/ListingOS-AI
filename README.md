# ListingOS AI (archived legacy project)

This repository contains the discontinued eBay seller-agent prototype. It is
not the current ListingOS product and does not describe
[listingos.expo.app](https://listingos.expo.app).

ListingOS is now a local marketplace for browsing, listing, messaging, offers,
reservations, and meetups. It does not process marketplace payments, escrow,
shipping, subscriptions, or third-party publishing.

Current website: [listingos.expo.app](https://listingos.expo.app)
